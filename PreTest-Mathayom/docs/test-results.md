# ผลการทดสอบ

รันเมื่อ 2026-11-02 18:26 ด้วย Node v24.16.0 คำสั่ง `node apps-script/tests/run.js`

ชุดที่ 1–6 ทดสอบตรรกะล้วนใน Logic.gs ส่วนชุดที่ 7 รัน Code.gs/Db.gs/Setup.gs จริงบน Google Sheet จำลองในหน่วยความจำ (ขนาด 1000×26 และ error เมื่อเขียนเกินขอบเหมือนของจริง) กับข้อสอบตัวอย่าง 15 ข้อ ใช้นาฬิกา server จำลองเพื่อเลื่อนเวลา ผลตรวจคลังเต็มอยู่ที่ [bank-check.md](bank-check.md)

ข้อจำกัด: ยังไม่ได้รันบน Apps Script จริง (ยังไม่ได้ deploy) เรื่องที่ต้องตรวจหลัง deploy อยู่ใน README หัวข้อ "รายการทดสอบหลัง deploy ครั้งแรก" โดยเฉพาะการเช็คอีเมลเจ้าของ (Session.getActiveUser) และการแสดงรูป SVG จาก Google Drive
