# MathLogic Prathom

Kumon-style daily math practice for Thai Grade 4 (ป.4, สสวท. curriculum): a Google Apps Script web app for the child (tablet, no login) plus a Google Sheet dashboard for parents.

- **Setup guide (Thai):** [README-TH.md](README-TH.md)
- **Paste-ready bundle:** `dist/` (`Code.gs`, `Index.html`, `appsscript.json`); rebuild with `node tools/build-bundle.js`
- **Source:** `apps-script/` · **Tests:** `npm test`
