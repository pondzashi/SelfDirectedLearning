# ติดตั้งระบบ Pre-test (Google Sheet + Apps Script)

คู่มือนี้เขียนสำหรับคนที่ไม่ใช่โปรแกรมเมอร์ ใช้เวลาประมาณ 20–30 นาที ทุกอย่างอยู่ในบัญชี Google ของคุณเองและไม่มีค่าใช้จ่าย

**สิ่งที่ต้องมี:** บัญชี Google ของผู้ปกครอง, คอมพิวเตอร์ (ทำผ่านมือถือไม่สะดวก) และไฟล์ในโฟลเดอร์นี้

| ไฟล์ในโฟลเดอร์ `apps-script/` | ประเภทไฟล์ใน Apps Script |
|---|---|
| `Code.gs`, `Db.gs`, `Logic.gs`, `Setup.gs` | **Script** |
| `Exam.html`, `Dashboard.html`, `Styles.html` | **HTML** |
| `appsscript.json` | ไฟล์ตั้งค่า (ขั้นตอนที่ 2.5) |

ไฟล์ข้อสอบอยู่ที่ `../data/`
- `questions_sample.csv` = ชุดเล็ก 15 ข้อ สำหรับลองระบบ
- `questions_full.csv` = คลังเต็ม 437 ข้อ (รวม 15 ข้อตัวอย่างแล้ว ถ้านำเข้าไฟล์นี้ **ไม่ต้อง** นำเข้าชุดเล็กซ้ำ) อ่านตรวจแบบสบายตาได้ที่ `../docs/questions_full_review.md`
- `images/` = รูปประกอบ 19 ไฟล์ ที่ข้อสอบความถนัดศิลป์ใช้ (ดูหัวข้อ "รูปประกอบโจทย์")

---

## ขั้นตอนที่ 1 — สร้าง Google Sheet

1. เปิด https://sheets.google.com แล้วกด **ว่าง (Blank)**
2. ตั้งชื่อไฟล์ (มุมซ้ายบน) เช่น `Pre-test ม.4`

## ขั้นตอนที่ 2 — ใส่โค้ด (วางทีละไฟล์)

1. ใน Google Sheet เมนู **ส่วนขยาย (Extensions) › Apps Script** จะเปิดแท็บใหม่
2. ตั้งชื่อโปรเจกต์ (มุมซ้ายบน "Untitled project") เช่น `Pre-test`
3. จะมีไฟล์ `Code.gs` อยู่แล้ว: คลิกเข้าไป ลบทั้งหมด แล้ววางเนื้อหาจากไฟล์ `Code.gs` ในโฟลเดอร์นี้
4. สร้างไฟล์ที่เหลือ: กดปุ่ม **＋** ข้างคำว่า "ไฟล์ (Files)"
   - เลือก **Script** แล้วพิมพ์ชื่อ `Db` (ไม่ต้องใส่ .gs) วางเนื้อหาจาก `Db.gs` ทำแบบเดียวกันกับ `Logic` และ `Setup`
   - เลือก **HTML** แล้วพิมพ์ชื่อ `Exam` วางเนื้อหาจาก `Exam.html` ทำแบบเดียวกันกับ `Dashboard` และ `Styles`
   - **ชื่อไฟล์ต้องตรงตามนี้เป๊ะ** (ตัวพิมพ์ใหญ่-เล็กมีผล)
5. ไฟล์ตั้งค่า: กดไอคอน ⚙️ **การตั้งค่าโปรเจกต์ (Project Settings)** ทางซ้าย › ติ๊ก **แสดงไฟล์ "appsscript.json" ในเครื่องมือแก้ไข** › กลับไปหน้า **เครื่องมือแก้ไข (Editor)** › เปิด `appsscript.json` ลบทั้งหมดแล้ววางเนื้อหาจากไฟล์ `appsscript.json` ในโฟลเดอร์นี้
6. กด 💾 **บันทึก** (หรือ Ctrl+S)

## ขั้นตอนที่ 3 — เตรียมแท็บใน Sheet และให้สิทธิ์

1. กลับไปที่แท็บ Google Sheet แล้ว **รีเฟรชหน้า** (F5) รอสักครู่จะมีเมนู **Pre-test** ขึ้นที่แถบเมนู
2. เมนู **Pre-test › 1. เตรียมระบบ**
3. Google จะขอสิทธิ์ (ครั้งแรกครั้งเดียว): กด **ดำเนินการต่อ** › เลือกบัญชีของคุณ
   - ถ้าเจอหน้า "Google ยังไม่ได้ยืนยันแอปนี้" ให้กด **ขั้นสูง (Advanced)** › **ไปที่ Pre-test (ไม่ปลอดภัย)** ที่ขึ้นแบบนี้เพราะเป็นสคริปต์ที่คุณเขียนเองและยังไม่ได้ส่งให้ Google ตรวจ ไม่ได้แปลว่ามีอันตราย
   - สิทธิ์ที่ขอ: แก้ไข Sheet, แสดงเมนู, ตั้งเวลาทำงานอัตโนมัติ, อ่านรูปจาก Drive (ถ้ามี), ดูอีเมลของคุณ (ใช้ล็อก Dashboard)
4. เลือกเมนู **Pre-test › 1. เตรียมระบบ** อีกครั้ง (ครั้งแรกอาจหยุดตอนขอสิทธิ์) จะได้แท็บ Questions / Sessions / Answers / Results / Settings / Reports และค่าเริ่มต้นในแท็บ Settings
5. ตรวจแท็บ **Settings**:
   - `owner_email` ต้องเป็นอีเมลของคุณ (ระบบเติมให้อัตโนมัติ)
   - `exam_title` เปลี่ยนเป็นชื่อเอกจริงได้
   - เวลาสอบ (`duration_min_*`), จำนวนข้อต่อทักษะ (`blueprint_*`), เกณฑ์สี (`color_*`) แก้ตามระเบียบการจริงได้ทันที ไม่ต้องแก้โค้ด (มีผลกับการสอบรอบใหม่)

## ขั้นตอนที่ 4 — ใส่ข้อสอบ (วาง CSV ต่อท้าย)

1. คลิกแท็บ **Questions**
2. เมนู **ไฟล์ › นำเข้า (File › Import)** › **อัปโหลด** › เลือกไฟล์ CSV เช่น `questions_sample.csv`
3. ตั้งค่าในหน้าต่างนำเข้า:
   - ตำแหน่งการนำเข้า: **เพิ่มต่อท้ายชีตปัจจุบัน (Append to current sheet)**
   - ประเภทตัวคั่น: **คอมมา (Comma)**
   - **เอาเครื่องหมายออก** ที่ "แปลงข้อความเป็นตัวเลข วันที่ และสูตร" (Convert text to numbers, dates, and formulas)
4. กด **นำเข้าข้อมูล** แล้ว **ลบแถวหัวตารางที่ซ้ำ** (แถวที่เขียนว่า id, subject, skill… ที่ต่อท้ายเข้ามา) ด้วยการคลิกขวาที่เลขแถว › ลบแถว
5. เมนู **Pre-test › 2. ตรวจคลังข้อสอบ** ระบบจะบอกจำนวนข้อที่ใช้ได้ แถวที่มีปัญหา และจำนวนข้อต่อทักษะ (แถวที่มีปัญหาจะไม่ถูกนำไปออกสอบ)

> เพิ่มข้อสอบชุดใหม่ภายหลังก็ทำแบบเดียวกัน (นำเข้าต่อท้าย) ไม่ต้องแก้โค้ด ถ้าต้องการพักข้อไหน ให้เปลี่ยนคอลัมน์ `status` เป็น `retired`
> ระบบเก็บข้อสอบไว้ในหน่วยความจำชั่วคราว 5 นาที ถ้าแก้ข้อสอบแล้วอยากเห็นผลทันที ใช้เมนู **Pre-test › ล้างแคชข้อสอบ**

## ขั้นตอนที่ 5 — เปิดใช้งานเป็นเว็บ (Deploy)

1. ในหน้า Apps Script กดปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy) › การทำให้ใช้งานได้รายการใหม่ (New deployment)**
2. กดไอคอน ⚙️ ข้าง "เลือกประเภท" › **เว็บแอป (Web app)**
3. ตั้งค่า:
   - คำอธิบาย: `v1`
   - **ดำเนินการในฐานะ (Execute as): ฉัน (Me)** ← สำคัญ ลูกจะได้ไม่ต้องมีสิทธิ์แก้ Sheet
   - **ผู้ที่มีสิทธิ์เข้าถึง (Who has access): ทุกคนที่มีบัญชี Google (Anyone with Google account)**
     - ลูกต้องล็อกอิน Google ตอนเปิดลิงก์สอบ (ใช้บัญชีใดก็ได้ ระบบไม่เก็บอีเมลลูก)
     - ถ้าลูก **ไม่มีบัญชี Google** ให้เลือก **ทุกคน (Anyone)** แทน แล้วตั้ง `parent_pin` ในแท็บ Settings เป็นรหัสที่คุณจำได้ เพราะในโหมดนี้ Google ไม่บอกอีเมลผู้เข้า Dashboard จึงต้องใช้รหัสแทน
4. กด **ทำให้ใช้งานได้ (Deploy)** › ให้สิทธิ์ถ้าถาม › คัดลอก **URL ของเว็บแอป** (ลงท้ายด้วย `/exec`) เก็บไว้
5. กลับไป Google Sheet เมนู **Pre-test › 3. ติดตั้งตัวตั้งเวลา** (ระบบจะตรวจทุก 5 นาที และปิดการสอบที่หมดเวลาให้ แม้ลูกปิดหน้าจอไปแล้ว)

## ขั้นตอนที่ 6 — ใช้งาน

- **Dashboard ผู้ปกครอง:** เปิด `URL ของเว็บแอป?page=dashboard` (เช่น `https://script.google.com/macros/s/xxxx/exec?page=dashboard`) ในเบราว์เซอร์ที่ล็อกอินบัญชีของคุณ แนะนำให้บุ๊กมาร์กไว้
- **สร้างลิงก์สอบให้ลูก:** ใน Dashboard แท็บภาพรวม › "สร้างลิงก์สอบ" เลือกโหมด (หรือ "ให้ลูกเลือกเอง") › กดสร้าง › คัดลอกลิงก์ส่งให้ลูก
  - **หนึ่งลิงก์เริ่มสอบได้ครั้งเดียว** ถ้าลูกรีเฟรชหรือปิดหน้า เปิดลิงก์เดิมจะกลับมาทำต่อด้วยเวลาที่เหลือจริง
  - ถ้าจะให้ฝึก Drill หลายรอบ ให้ใส่ "จำนวนลิงก์" มากกว่า 1 ได้ในครั้งเดียว
- **เฉลย:** ค่าเริ่มต้นคือ "รอผู้ปกครองเปิดให้" กด "ดูทีละข้อ" ที่รอบนั้น › "เปิดเฉลยให้ลูก" (เปลี่ยนเป็นเห็นทันทีได้ในการ์ด "การแสดงเฉลย")
- **ลูกแจ้งเฉลยผิด:** จะขึ้นในการ์ด "ข้อที่ลูกแจ้งว่าเฉลยผิด" กด "เฉลยถูกแล้ว" หรือ "พักข้อนี้" (พักแล้วข้อนั้นจะไม่ถูกสุ่มออกอีก) ถ้าเฉลยผิดจริง แก้ในแท็บ Questions แล้วเปลี่ยน `status` กลับเป็น `active`

## ✅ รายการทดสอบหลัง deploy ครั้งแรก (ทำก่อนให้ลูกใช้จริง ประมาณ 10 นาที)

ใช้ข้อสอบชุดเล็ก และตั้ง Settings ชั่วคราว `duration_min_english` = `2` (ทดสอบเสร็จแล้วตั้งกลับเป็น 40)

1. เปิด Dashboard ด้วยบัญชีของคุณ → ต้องเห็นหน้า Dashboard (ถ้าขึ้น "ไม่มีสิทธิ์" ดูหัวข้อแก้ปัญหา)
2. เปิด Dashboard ในหน้าต่างไม่ระบุตัวตน (Incognito) ด้วยบัญชีอื่น → ต้องขึ้น "ไม่มีสิทธิ์"
3. สร้างลิงก์ "Mock รายวิชา" วิชาอังกฤษ → เปิดลิงก์ใน Incognito → กดเริ่มสอบ → ตอบ 2 ข้อ → **รีเฟรชหน้า** → คำตอบเดิมยังอยู่ และเวลาเดินต่อ ไม่รีเซ็ต
4. ดูแท็บ Sessions ใน Sheet → มี `started_at` และ Answers มีแถวของรอบนี้
5. ปล่อยให้หมดเวลา → ระบบขึ้น "หมดเวลา" และส่งให้อัตโนมัติ → เปิดลิงก์เดิมอีกครั้ง → ต้องเริ่มสอบใหม่ไม่ได้
6. ใน Dashboard เห็นรอบนี้ ป้าย "สอบรายวิชา" กด "ดูทีละข้อ" → "เปิดเฉลยให้ลูก" → ลิงก์ของลูกกด "ตรวจว่าเปิดเฉลยแล้วหรือยัง" → เห็นเฉลย
7. ตั้ง `duration_min_*` กลับเป็นค่าจริง

## อัปเดตโค้ดภายหลัง (สำคัญ)

แก้โค้ดใน Apps Script แล้ว **ลิงก์ `/exec` ยังใช้เวอร์ชันเดิมจนกว่าจะออกเวอร์ชันใหม่**:
**Deploy › จัดการการทำให้ใช้งานได้ (Manage deployments)** › ✏️ แก้ไข › เวอร์ชัน: **เวอร์ชันใหม่ (New version)** › Deploy (URL เดิม ไม่ต้องแจกลิงก์ใหม่)
อย่ากด "New deployment" ซ้ำ เพราะจะได้ URL ใหม่

## ⚠️ ข้อห้ามในแท็บ Sessions / Answers / Results

**ห้ามเรียงลำดับ (Sort), ห้ามลบแถว และห้ามแทรกแถว** ในสามแท็บนี้ เพราะระบบจำตำแหน่งแถวคำตอบของแต่ละรอบไว้ (`ans_row_start`, `ans_count`) ถ้าแถวเลื่อน ผลสอบจะเพี้ยน
ถ้าต้องการดูแบบเรียง ให้ใช้ **ข้อมูล › สร้างมุมมองตัวกรอง (Create filter view)** ซึ่งไม่ย้ายแถวจริง ส่วนแท็บ Questions, Settings, Reports แก้/เรียงได้ตามสะดวก

## แก้ปัญหา

| อาการ | วิธีแก้ |
|---|---|
| ไม่มีเมนู Pre-test | รีเฟรช Google Sheet รอ 5–10 วินาที ถ้ายังไม่มี ตรวจว่าไฟล์ `Setup.gs` ถูกวางและบันทึกแล้ว |
| Dashboard ขึ้น "ไม่มีสิทธิ์" ทั้งที่เป็นบัญชีเจ้าของ | ตรวจ `owner_email` ใน Settings สะกดตรงกับบัญชีที่ล็อกอิน (ถ้าล็อกอินหลายบัญชีในเบราว์เซอร์เดียว Google อาจใช้บัญชีแรก ลองใช้ Incognito ล็อกอินบัญชีเดียว) ถ้ายังไม่ได้ ตั้ง `parent_pin` แล้วเข้าด้วยรหัส |
| ลูกเปิดลิงก์แล้วต้องขอสิทธิ์เข้าถึง | ตรวจว่าตั้ง "Execute as: Me" และ "Who has access" ไม่ใช่ "Only myself" |
| "ไม่มีข้อสอบในคลังสำหรับการสอบแบบนี้" | ยังไม่ได้นำเข้าข้อสอบ หรือแถวผิดรูปแบบ ใช้เมนู ตรวจคลังข้อสอบ |
| ได้ข้อสอบน้อยกว่าที่ตั้งไว้ | คลังมีข้อของทักษะนั้นไม่พอ ระบบสอบเท่าที่มีและบันทึกจำนวนที่ขาดไว้ใน `Sessions.config_json` (shortfall) |
| แก้ Settings/ข้อสอบแล้วไม่เปลี่ยน | การตั้งค่ามีผลกับรอบใหม่เท่านั้น ข้อสอบรอแคช 5 นาที หรือใช้เมนู ล้างแคชข้อสอบ |
| แก้โค้ดแล้วเว็บไม่เปลี่ยน | ต้องออก "เวอร์ชันใหม่" (หัวข้ออัปเดตโค้ด) |

## รูปประกอบโจทย์ (ถ้ามี)

คลังเต็มมีข้อสอบความถนัดศิลป์ 21 ข้อที่ใช้รูปจากโฟลเดอร์ `data/images` (คอลัมน์ `image_url` เขียนไว้แล้วเป็น `drive:ชื่อไฟล์.svg`) ต้องทำขั้นตอนนี้ก่อนให้ลูกสอบวิชาความถนัดศิลป์ ไม่งั้นข้อเหล่านั้นจะขึ้นว่าโหลดรูปไม่สำเร็จ

1. สร้างโฟลเดอร์ใน Google Drive (ไม่ต้องแชร์) แล้วลากไฟล์ทั้งหมดใน `data/images` ไปวาง เปิดโฟลเดอร์ คัดลอก ID จาก URL (ส่วนท้ายหลัง `/folders/`) ใส่ใน Settings › `images_folder_id`
2. ในคอลัมน์ `image_url` ของข้อสอบใส่ `drive:ชื่อไฟล์.png` (หรือ `drive:<fileId>` หรือ URL ที่ขึ้นต้นด้วย https://)
3. คอลัมน์ `explanation_image_url` ใช้รูปประกอบคำอธิบายได้แบบเดียวกัน

### Deploy ด้วย clasp

```bash
npm install -g @google/clasp
```
```bash
clasp login
```
คัดลอก `.clasp.json.example` เป็น `.clasp.json` ใส่ Script ID (Apps Script › Project Settings) แล้ว
```bash
clasp push
```
(`.claspignore` กันโฟลเดอร์ tests ไม่ให้ถูกส่งขึ้นไป) จากนั้น deploy เวอร์ชันใหม่ผ่านหน้าเว็บ หรือ `clasp deploy -i <deploymentId>`

### โครงสร้าง
- `Logic.gs` ตรรกะล้วน (จับเวลา, สุ่มข้อ, คะแนน, Drill) ไม่เรียกบริการ Google
- `Db.gs` อ่าน/เขียน Sheet, Settings, คลังข้อสอบ (แคชแบบแบ่งชิ้นใน CacheService), รูปจาก Drive
- `Code.gs` route หน้า, API `api_*` (หน้าสอบ, ใช้ session_id เป็นกุญแจ), `dash_*` (ตรวจสิทธิ์เจ้าของทุกครั้ง), `sweepExpiredSessions`
- `Setup.gs` โครงสร้างแท็บ, ค่าเริ่มต้น, เมนู, ตรวจคลังข้อสอบ
- ฟังก์ชันที่ลงท้ายด้วย `_` เรียกจากหน้าเว็บไม่ได้ (เป็นกติกาของ Apps Script)
