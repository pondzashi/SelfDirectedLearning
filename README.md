# SelfDirectedLearning
Web app: Kumon-style daily math practice for Thai Grade 4. Timed drills, observation and analytical thinking. Tablet-friendly, no login. Sheet: Parent dashboard for MathLogic Prathom: results, levels, review queue, question bank, progress charts, monthly report.
